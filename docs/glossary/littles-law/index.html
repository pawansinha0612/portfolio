What is Little's Law?

Little's Law says that the average number of items in a stable system equals their average arrival rate multiplied by the average time each one spends in the system, written L = λ × W.

Why it matters

It is the most useful single formula in capacity planning. It sizes virtual users, thread pools and connection pools, and it checks whether test results are believable.

An example

An API handles 200 requests a second with an average response time of 0.25 s. On average 200 × 0.25 = 50 requests are in flight. A load test of 50 requests a second with users who each spend 0.8 s waiting plus 5 s thinking needs 50 × 5.8 = 290 virtual users.

How to measure or test it

Use averages from a steady-state window. If the numbers from your test don't satisfy the law (for example, users × iterations per user doesn't match measured throughput), something in the test or the measurement is wrong.

Common mistakes

  • Applying it during ramp-up, when the system is not stable.
  • Using p95 response time in place of the average.
