    How it works

    What the check looks at

    The check asks Google PageSpeed Insights to load your page once, on a mid-range phone over a mobile connection (or a desktop), and turns the results into plain English:

    • How fast the main content appears (Largest Contentful Paint). Google's target is 2.5 seconds or less.
    • How quickly the page responds to taps, measured as time the browser is blocked running scripts.
    • Whether things jump around while loading (Cumulative Layout Shift, target 0.1 or less).
    • How long your server takes to answer. This is the number that grows fastest under heavy traffic.
    • Page weight, images and third-party apps: what's being downloaded, and what could go.

    If Chrome has enough data about your site, you also see how fast it is for real visitors over the last 28 days.

    FAQ

    Does this check put load on my website?

    No. Google loads the page once, like one visitor would. It's safe to run on any public site.

    Why is my score different every time?

    Each check is a single page load, so network conditions, ads and third-party scripts move it a few points. Look at the findings, not the exact score.

    Will a good score mean my site survives Black Friday?

    Not on its own. A fast page for one visitor can still fail with five thousand. Sale-day problems come from servers, databases, payment providers and apps under load. That's what a peak-readiness load test checks.

    What happens to the address I enter?

    It's sent to Google PageSpeed Insights to run the check, and logged with the score so I can see how the tool is used. If you ask for the report by email, I get your name and email too, and may reply once. That's it.
