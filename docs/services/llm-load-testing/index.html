Questions

Common questions

Won't a load test cost a fortune in tokens?

Usually less than a day of real traffic. I model the cost before every run, use short ramps first, and test with a separate key with a spending cap. Where it makes sense, I also test against a mock of the model so your own backend can be tested without paying per token.

Is it allowed to load test an AI provider's API?

You are testing your own account within its limits, which is what the limits are for. For very large tests I'll ask you to tell your provider or account manager first, and we always use a key that can't throttle production.

We host our own model on GPUs. Can you test that?

Yes. vLLM, Ollama and other OpenAI-compatible servers are tested the same way, and the results show where queueing starts: batch size, GPU memory or the number of replicas.

Which providers do you work with?

Anything with an HTTP API: OpenAI, Azure OpenAI, Anthropic, OpenRouter and other gateways, and self-hosted models. The scripts are plain k6, so they stay with your team.
