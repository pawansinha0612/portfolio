Gaming & Lottery

The Lottery Corporation

2025 to present

An AI-powered performance testing framework, adopted company-wide

Challenge: Powerball, Oz Lotto and Keno see massive traffic spikes on draw nights, and hand-scripting load tests couldn't keep up with how often the team released.

What I did: Built a k6 framework that generates typed API clients from OpenAPI specs, uses GitLab Duo to turn plain-English scenarios into ready-to-run tests, and runs in GitLab CI on every deployment. Added live Grafana/InfluxDB and Kibana dashboards, and used Dynatrace to trace slow Oracle queries, memory leaks and GC pressure.

Outcome: Writing test scripts now takes minutes instead of days, every deployment passes a performance gate, and the framework became the standard approach across engineering squads.

Global Payments

Visa

2022 to 2024

Scalability for high-volume transaction processing

Challenge: Microservices processing card transactions at very high volume, on Kubernetes and cloud, where any slowdown means lost revenue.

What I did: Led end-to-end performance engineering using LoadRunner (C, manual correlation) and JMeter in CI/CD. Planned capacity for high-criticality services, and diagnosed bottlenecks across .NET, SQL Server and Postgres.

Outcome: Agreed benchmarks for each service, clear root-cause and tuning advice for developers, and a testing team mentored in AI-assisted workflows.
