Learn k6 load testing in 7 days

One short lesson in your inbox each morning, each with a small task. By day 7 you'll have a realistic load test with SLO thresholds and test data that runs in your CI pipeline, and you'll know how to read the results.

  1. Day 1

    Your first load test in 10 minutes

    Install k6, write a script, and read the three numbers in the summary that matter.

  2. Day 2

    Model real traffic

    Closed vs open models, arrival-rate scenarios, and sizing VUs with Little's Law.

  3. Day 3

    Checks and thresholds

    Turn SLOs into pass/fail rules, per endpoint, that fail the build when they break.

  4. Day 4

    Realistic test data

    CSV data with SharedArray, logins, correlation and keeping secrets out of scripts.

  5. Day 5

    Tags, groups and custom metrics

    Find the slow step, avoid metric explosions and track business numbers.

  6. Day 6

    Run it in CI

    A GitHub Actions workflow with smoke tests on every pull request.

  7. Day 7

    Read results and find the bottleneck

    The order I read a summary in, the live dashboard, and what to check on the server.
