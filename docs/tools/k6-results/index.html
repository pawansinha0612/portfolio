How to get the output

Three ways to give it your results

  1. Copy from the terminal. After k6 run script.js finishes, copy everything from █ THRESHOLDS (or the metric lines on older k6) to the end. For the full breakdown of connection, waiting and download times, run with --summary-mode=full.
  2. Export a JSON file. k6 run --summary-export=summary.json script.js, then open summary.json and paste its contents.
  3. From handleSummary(). If your script has a handleSummary(data) function, write JSON.stringify(data) to a file and paste that.

What this can and can't tell you

  • The summary shows what happened over the whole test. It can't show when: a system that was fine for 9 minutes and fell over in the 10th looks like a mild tail here. Look at results over time (k6's web dashboard: K6_WEB_DASHBOARD=true k6 run script.js, or Grafana).
  • It can't see your servers. The hints point at likely causes; confirm them with server CPU, memory, garbage collection, database and pool metrics from the same time window.
