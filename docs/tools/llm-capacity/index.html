How the numbers work

Why AI features hit limits that normal APIs don't

  • The token limit usually bites first. A chatbot with a 1,500-token system prompt and retrieved context uses 1,800 tokens per question. 150 questions a minute is 270,000 tokens a minute, long before any requests-per-minute limit.
  • Agents multiply everything. Each user request becomes several model calls, and the context grows with every step. Set "model calls per request" honestly.
  • Limits are per minute, traffic isn't. Even at 70% of the limit on average, a burst inside one minute can get 429s. That's why the result says "tight" from 70%.
  • Slow answers need lots of concurrency. At 3 answers a second and 6 seconds each, 18 are in flight at once. Your gateway, connection pool and any serverless limit must allow that.
  • A calculation is not a test. Real limits depend on your tier, region and how the provider meters them. The load test shows what really happens, including your retries.
