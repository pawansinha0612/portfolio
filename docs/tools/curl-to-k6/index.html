How to use it

From a browser request to a load test in two minutes

  1. Copy the request. In Chrome or Edge: open DevTools (F12) → Network → right-click the request → Copy → Copy as cURL (bash). In Firefox: right-click → Copy Value → Copy as cURL. In Safari, turn on the Develop menu first, then use Web Inspector → Network.
  2. Paste it above and pick a load model. Use virtual users to imitate a number of people clicking through, or arrival rate to hit a target number of requests per second whatever the response time.
  3. Install k6 (brew install k6, winget install k6 or the Docker image grafana/k6) and run k6 run script.js.
  4. Read the result. Paste k6's end-of-test summary into the k6 results explainer for a plain-English verdict.

Before you point it at production

  • Tokens copied from a browser expire. For anything longer than a quick try, log in inside the script (or once in setup()) and reuse the token.
  • Use test data. A journey that creates orders or sends emails will do it thousands of times. Agree on a test account and a clean-up plan first.
  • Ask before you load test a system you don't own. To a firewall, a load test looks like an attack.
  • Start small. Run 1 VU for 30 seconds as a smoke test, then build up.
