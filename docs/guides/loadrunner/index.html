LoadRunner guides

Practical how-tos for LoadRunner, the tool many Australian banks, insurers and government agencies still run their release tests on. OpenText now sells it as Professional Performance Engineering (formerly LoadRunner Professional), with VuGen, Controller and Analysis inside. These guides follow the 26.x documentation. Menu labels move between releases, so check your version's help when a screen looks different.

A note on names. In 2025 OpenText renamed the family: LoadRunner Professional became OpenText Professional Performance Engineering, LoadRunner Enterprise became Enterprise Performance Engineering, LoadRunner Cloud became Core Performance Engineering and LoadRunner Developer became Performance Engineering for Developers. Teams, job ads and these guides still say "LoadRunner", and the components keep their names: VuGen, Controller, Analysis and load generators.
