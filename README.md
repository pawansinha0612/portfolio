# pawansinha.com.au

Website, free tools and content for **Pawan Sinha, Performance Testing Consultant** (Melbourne).

**Live site:** https://pawansinha.com.au · **Tools:** https://pawansinha.com.au/tools/ ·
**Blog:** https://pawansinha.com.au/blog/

## What's on the site

- **Free performance testing tools** that run in your browser, with nothing uploaded:
  - converters to k6: curl, JMeter, Postman, OpenAPI
  - results analysers: k6, JMeter .jtl, comparing two runs, thread dumps, GC logs
  - calculators: capacity, SLO, LLM capacity
  - test generators, and a speed check for online shops
- **Learning:** 90+ guides, a glossary, tool comparisons, interactive explainers, interview prep for six roles, a
  k6 email course and two games.
- **Daily blog** on advanced performance engineering, with an interactive calculator in each post.
- **Side projects:** a [browser video editor](https://pawansinha.com.au/projects/video-editor/) and the
  [Melbourne Deal Finder](https://pawansinha.com.au/projects/deal-finder/).
- **Services and products:** [services](https://pawansinha.com.au/#services) and [shop](https://pawansinha.com.au/shop/).

## How it's built

Plain HTML, CSS and JavaScript served by GitHub Pages from `docs/`. There's no framework on the main site. A few
sections are generated by small Python scripts, and GitHub Actions keeps everything up to date.

```
docs/            The website (what GitHub Pages serves)
  tools/         Browser tools. Each one's logic is in its own .js file, tested in toolkit-tests/
  widgets.js     Interactive calculators used in blog posts
blog/            Posts (Markdown), the page builder, the share-image maker, AI drafting and its automatic review
guides/ glossary/ compare/ explain/ interview-prep/ services/
                 Sources for the generated sections (each has a build.py)
video-editor/    The browser video editor (React + TypeScript + Vite), built into docs/projects/video-editor/
packages/to-k6/  Command-line converter to k6
enquiry/         Google Apps Script backend for the site's forms and emails
health/          Weekly site health check
jobs/ search/    Daily jobs page and the site search index
toolkit-tests/   Tests for the browser tools
.github/         GitHub Actions: blog drafts, review and publishing, page rebuilds, health check, search index
```

**Run the tests:** `node toolkit-tests/<file>.js` for the tools, and `cd video-editor && npm test` for the editor.

**Preview locally:** `python3 -m http.server --directory docs`, then open http://localhost:8000.
