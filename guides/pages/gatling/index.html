When Gatling is a good fit

  • Your team works in Java, Kotlin or Scala and wants load tests in the same language, build and code review as the service.
  • You need high load from few machines: Gatling's async engine is efficient.
  • You want a detailed HTML report with no extra setup.

Weighing it against other tools? Read k6 vs Gatling, or see the k6 and Locust guides. The ideas behind injection profiles are in the load profiles and queueing explainers.
