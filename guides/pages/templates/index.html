Free performance testing templates

Five one-page templates that cover a performance test from the first strategy meeting to the go-live decision. Read them here, download them as Markdown, or print them to PDF.

1 · Once per product

Test strategy

Scope, business risks, targets, which tests run when, environments, tools and who signs off.

 2 · Once per release

Test plan

Objective, NFRs, workload, the tests to run with pass criteria, environment gaps, data and risks.

 3 · Before scripting

Workload model sheet

Peak-hour volumes in, iterations per second, virtual users and pacing out. With a worked example.

 4 · After the test

Results report

Verdict first, key numbers against targets, resource use, findings with evidence and next steps.

 5 · Before go-live

Go-live sign-off

A 14-check go/no-go list across performance, capacity, resilience, observability and release.

How they fit together

The strategy sets the rules for a product: which risks matter, which tests run and who decides. Each release then gets a short plan. The plan's load numbers come from the workload model. After the test, the report gives the verdict. The go-live sign-off turns that verdict and everything around it into a decision with names on it.

Small team, one release? Skip the strategy and start with the plan.

Using the files

  • Markdown opens in any text editor, renders on GitHub, GitLab and most wikis, and pastes into Confluence or Notion.
  • Print or save as PDF from any template page. The site menu and the how-to notes are left out of the printout.
  • Grey boxes are placeholders. Replace them, then delete the guidance notes before you share the document.
  • They work with any load testing tool. New to the tools? Start with the learning path.
